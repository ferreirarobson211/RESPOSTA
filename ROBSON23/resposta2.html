Model (Modelo)

O Model é responsável por representar os dados e as regras de negócio de uma aplicação.

Principais funções do Model

  • Armazenar e organizar os dados.
  • Realizar operações com o banco de dados.
  • Aplicar regras de negócio.
  • Validar informações.

Exemplo

Em um sistema de cadastro de usuários, o Model é responsável por armazenar informações como nome, e-mail e senha.
